# Django WebSite on Class -_-

## How to setup this project

1. Create virtual environment
```sh {"runme": "true"}
python -m venv venv
```

2. Activate virtual environment
```sh {"runme": "true"}
source venv/bin/activate
```

3. Install packages
```sh {"runme": "true"}
pip install -r requirements.txt
```

4. Run server
```sh {"runme": "true"}
python manage.py runserver
```
